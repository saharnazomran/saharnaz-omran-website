SAHARNAZ OMRAN — WEBSITE V1

This is a first responsive static website draft built from the approved homepage direction.

PREVIEW
- Open index.html in a browser.
- For a local development server, run: python3 -m http.server 8000
  Then visit http://localhost:8000

EDITING
- Main page content: index.html
- Colors, typography, layout, responsive rules: styles.css
- Mobile navigation: script.js
- Replace images inside assets/ while keeping the same filenames, or update the image paths in index.html.

IMPORTANT PLACEHOLDERS
- hello@example.com is a placeholder email address.
- Instagram URL is not yet connected.
- Project titles and descriptions are provisional and should be replaced with verified project details.
- Google Fonts are loaded online; system serif/sans fallbacks are included.

No image filters or color overlays are applied to the supplied photographs/artworks.
